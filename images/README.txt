FOTO ASLI KOMPONEN DIAGRAM (opsional)
=====================================
Letakkan foto komponen di folder ini dengan nama persis seperti berikut
(format webp, png, jpg, atau jpeg - dicari berurutan; webp dipakai lebih dulu karena jauh lebih kecil):

    aki.png            -> Aki / battery
    fuse.png           -> Fuse (sekring)
    kunci-kontak.png   -> Kunci kontak (ignition switch)
    relay.png          -> Relay starter
    selenoid.png       -> Selenoid / magnetic switch starter
    motor-starter.png  -> Motor starter
    pinion.png         -> Pinion gear (ikut bergeser maju saat engage)
    flywheel.png       -> Flywheel / ring gear
    mesin.png          -> Mesin

Diagram memuatnya otomatis. Komponen yang fotonya belum ada tetap memakai
gambar skema, jadi boleh mengisi satu per satu. Tombol SKEMA/FOTO di toolbar
simulator mengganti tampilan (berguna untuk membandingkan foto dengan simbol).

Saran agar hasil bagus:
- Pakai PNG/WEBP dengan latar TRANSPARAN (foto "cut-out"), terutama flywheel:
  foto flywheel ikut berputar saat cranking, jadi sebaiknya bulat dari tampak depan.
- Rasio mendekati kotak kecil (mis. 400 x 300 px). Foto di atas 1000 px tidak perlu.
- Buka lewat server lokal (node server.js) agar gambar dimuat dengan benar.
- Gunakan foto milik sendiri atau berlisensi bebas (CC0 / CC-BY, mis. Wikimedia
  Commons) dan catat atribusi pembuatnya di file credits.txt di folder ini.
