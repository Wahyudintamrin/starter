MODEL 3D ASLI MOTOR STARTER (opsional)
======================================
Letakkan file model 3D motor starter dengan nama:

    models/starter-motor.glb

3D Lab akan memuatnya otomatis saat dibuka melalui server lokal
(contoh: python -m http.server 8000 lalu buka http://localhost:8000).
Jika index.html dibuka langsung (klik ganda), gunakan tombol
"MUAT FILE .GLB..." di 3D Lab atau seret file .glb ke area 3D.

Syarat file:
- Format glTF 2.0 biner (.glb). File .gltf hanya didukung bila buffer tertanam.
- Tanpa kompresi Draco / Meshopt (ekspor ulang tanpa kompresi bila perlu,
  misalnya lewat Blender: File > Export > glTF 2.0, matikan "Compression").
- Gunakan model dengan lisensi yang mengizinkan pemakaian untuk pendidikan
  (mis. CC-BY / CC0) dan cantumkan atribusi pembuatnya.

Model asli ditampilkan sebagai tampilan statis (bisa diputar, cutaway,
exploded). Animasi kerja sistem (solenoid, pinion, cranking) tetap memakai
MODEL SIMULASI.
